How the scoring works

Every score is a transparent, hand-designed weighted sum over four axes — no machine learning, no external ratings. Each axis is computed from metrics extracted directly from the font files themselves (via fontTools): x-height, cap-height, category, weight class, and an approximate stroke-contrast measurement rendered and measured geometrically on the glyph 'O'.

Built by an evolving process

This tool went through six build milestones (extraction → database → scoring → recommendation → rendering → web UI), then a self-directed improvement loop that assesses a gap, proposes it, implements, re-validates, and commits — each step logged before it happens, not after. See EVOLUTION_LOG.md and PROGRESS.md in the project repo for the full, dated record.
